## 🧩 About

**Among Us overlay Menu** is a curated list of Among Us open-source tools:

- **Overlays** — on-screen helpers, layout notes, task tracker, role hints
- **Quality-of-Life Helpers** — map catalog, skin notes, lobby overlay notes
- **Research Notes** — task layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Session Helpers
- Task Tracker — keep task progress visible on screen
- Role Notes — review crew and impostor role hints
- Map Overlay — outline map rooms and vents for study
- Playback Notes — review past rounds in single-player practice

### 🎨 Catalog & Cosmetics
- Cosmetic Catalog — browse hats, skins, pets, visors
- Custom Skin Notes — organize player cosmetics
- Color Reference — improved crewmate color visibility

### 🏋️ Practice Layout
- Practice Notes — segment study on any layout
- Vent Map Notes — study vent connections on each map
- Task Route Notes — chain task routes in the editor

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
| `process_name` | String | `"Among Us.exe"` | Target process |
| `safe_mode` | Boolean | `true` | Keep conservative defaults |
